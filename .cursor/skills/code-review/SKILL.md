# Code Review Skill

## Process

1. Read the original issue and acceptance criteria.
2. Inspect the full diff (not only the latest commit).
3. Run through the checklist in the reviewer agent definition.
4. Emit findings grouped by severity.
5. State residual risks.

Prefer a different model from the implementer when the environment allows it.
